# Code of conduct

Recapture follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, discussions and any other project space.

In short: be kind and patient, give feedback on the work and not on the person, and accept feedback the same way. Harassment, insults and personal attacks are not accepted.

The maintainers can hide or remove content that breaks this code, and can block a person from the project for a time or for good.
